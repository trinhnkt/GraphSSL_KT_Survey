# Evidence coding rule

For each nontrivial paper/model/experiment code, preserve field-level traceability.

Required evidence fields:
- entity level;
- entity id;
- field name;
- coded value;
- coding basis;
- evidence source type;
- evidence locator;
- short evidence note;
- source;
- coder id/type/confidence;
- adjudication status.

Prefer primary full text and author artifacts.
Do not copy long passages; store concise paraphrases and locators.
