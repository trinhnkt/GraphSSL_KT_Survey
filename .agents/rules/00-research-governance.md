# Research governance

Always preserve the frozen survey scope, RQs, and SLR protocol.

Never:
- silently modify `_LOCKED` files;
- fabricate missing paper details;
- transform seed-corpus counts into PRISMA counts;
- mass-code before the codebook is frozen;
- use test data to justify train-only graph claims;
- treat third-party implementations as author artifacts.

If a source does not support a code, use `NR`, `NA`, `UNCLEAR`, or `TBD_VERIFY`.

All substantive protocol changes require a dated entry in:
`00_protocol/protocol_deviations.md`.
