# code-one-paper

Description: Code one pilot or included KT paper using the current codebook and field-level evidence.

Steps:
1. Verify the paper's identity and current codebook version.
2. Confirm legal/full-text access status.
3. Code PAPER fields.
4. Split substantive model variants and code MODEL fields.
5. Split dataset/protocol combinations and code EXPERIMENT fields.
6. Add field-level evidence.
7. Record boundary/codebook issues separately.
8. Run protocol audit.
9. Save a versioned artifact; do not modify locked files.
