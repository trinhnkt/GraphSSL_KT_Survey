# audit-paper-metadata

Description: Verify bibliographic metadata and version relationships for one or more survey papers.

Steps:
1. Start from current corpus metadata.
2. Verify DOI/title/authors/year/venue on official publisher or proceedings sources.
3. Check for peer-reviewed vs preprint version.
4. Check conference/journal extension relationship.
5. Record conflicts without overwriting silently.
6. Produce/update metadata conflict log.
