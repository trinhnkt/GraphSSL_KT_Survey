## Inventory of Supplementary CSV Artifacts

1. **supplementary_corpus_inventory.csv**: Complete per-paper metadata and gateway status for all primary core papers ( = 37$).
2. **supplementary_ssl_taxonomy_Ns9.csv**: SSL taxonomy for the locked \(N_S=9\) papers only (author sign-off 2026-09-13). Do **not** upload `supplementary_coding_matrix.csv` (historical 14-row file; five G-only papers are not SSL).
3. **supplementary_quality_scores.csv**: Itemized QA1--QA8 scores for the 37 primary-core papers. `raw_score` equals the component sum with QA6 capped at 2. HIGH 11 / MODERATE 26 / mean 0.76 (KT029, KT033, KT035, KT038, KT044, KT050, KT060, KT064, KT066, KT070, KT077). Extra inventory KT078 and KT080--KT083 are omitted. The previous inconsistent file is kept as `supplementary_quality_scores_v1_as_deposited.csv`. QA7 `NA` sensitivity is in `supplementary_quality_scores_v2_QA7_sensitivity.csv`.
4. **supplementary_prisma_exclusions.csv**: Stage 2 full-text eligibility screening exclusion records ( = 98$ excluded studies) with explicit primary exclusion codes ($\text{EC1}--\text{EC7}$) and evidence locators.
5. **supplementary_doi_audit.csv**: Reference DOI audit and physical PDF deposit status for all 43 references cited in the manuscript.
6. **Encoder bar chart** (`figures/fig_meta_analysis_charts.pdf`): repeats the encoder totals already printed in the provenance-by-encoder table. It is not printed in the main text. The provenance count chart (`figures/fig_graph_construction_pipeline.pdf`) repeats 19/8/9 and is also omitted from the main text. The taxonomy figure stays in the article.
