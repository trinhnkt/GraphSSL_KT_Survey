# TLT format check (v1.4.3)

Date: 2026-09-13

Official source used: [TLT Author Resources](https://ieee-edusociety.org/publication/tlt/tlt-author-resources) (IEEE Education Society).

## What is not in this repository

`TLT-instructions-only.pdf` is issued through the IEEE Template Selector. It is **not** mirrored in this repo and was **not** compared side-by-side with the compiled PDF. That comparison remains an author upload step.

## What was compared

| Requirement (official TLT page) | This package |
|---|---|
| Article type | Survey and Tutorial (stated in cover letter) |
| Page cap (from 1 Jan 2025) | 18 double-column pages; compiled MS is ~11 |
| Template | `IEEEtran` `[lettersize,journal]` V1.8b (same family as `15. Check list/IEEE-Transactions-LaTeX2e-templates-and-instructions/`) |
| PDF for initial submission | Produced from `manuscript_TLT_FORMATTED_v1.3.tex` |
| ORCID for all authors | Present in `\thanks` |
| IEEE reference style | `IEEEtran.bst` + `references.bib` |
| Dual CS + learning-technology bar | Taxonomy/audit + ITS table (`tab:its_implications`) |
| AI-generated text disclosure | Acknowledgment section added |
| Submission portal | IEEE Author Portal (cover letter); TLT page also mentions ScholarOne for the PDF |

## Residual format risk

Desk formatting rejection is still possible if the Template Selector `TLT-instructions-only.pdf` differs in headers, biography layout, or copyright-line placement from the generic Transactions journal sample. Do that visual check before upload.
